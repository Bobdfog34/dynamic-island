# Dynamic Island (Живой остров) для Android

Клон «Dynamic Island» с iPhone: плавающий остров вверху экрана, который показывает
уведомления, музыку, зарядку и таймер, поддерживает жесты и кастомизацию.

## Возможности

- 🔔 **Уведомления** — показ входящих уведомлений прямо в острове
- 🎵 **Музыка** — текущий трек и исполнитель (через MediaSession)
- ⚡ **Зарядка** — анимация при подключении питания
- 🔋 **Низкий заряд** — предупреждение при 15% и ниже
- ⏱ **Таймер** — живой отсчёт в острове
- 👆 **Жесты** — тап (развернуть/свернуть), перетаскивание пальцем, двойной тап (настройки)
- 🎨 **Кастомизация** — ширина, высота, скругление, отступ сверху, прозрачность, цвет, рамка
- 🚀 **Автозапуск** при включении телефона

## Как собрать APK через GitHub (без ПК)

1. Создай новый репозиторий на GitHub (кнопка **New repository**), например `dynamic-island`.
2. Загрузи туда все файлы этого проекта (кнопка **Add file → Upload files**, перетащи папки `app`, `.github`, `gradle.properties`, `settings.gradle.kts`, `build.gradle.kts`).
   - Важно: папка `.github/workflows/build.yml` должна попасть в репозиторий.
3. После загрузки открой вкладку **Actions** — сборка запустится автоматически.
4. Дождись зелёной галочки ✅ (примерно 3–5 минут).
5. Открой завершённый запуск → внизу блок **Artifacts** → скачай **DynamicIsland-debug**.
6. Распакуй архив и установи `app-debug.apk` на телефон (разреши установку из неизвестных источников).

Если сборка не запустилась: **Actions → Build APK → Run workflow**.

## Как пользоваться

1. Открой приложение.
2. Нажми **«Разрешить показ поверх других окон»** и включи переключатель.
3. Нажми **«Доступ к уведомлениям»** и включи доступ для Dynamic Island.
4. Включи переключатель **«Включить остров»**.
5. Настрой внешний вид ползунками и нажми **«Применить настройки»**.

Остров можно перетаскивать пальцем. Тап — развернуть/свернуть.

## Локальная сборка (если есть Android Studio)

```bash
gradle assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Технологии

- Kotlin, AndroidX, Material Components
- `WindowManager` overlay + `ForegroundService`
- `NotificationListenerService` + `MediaSessionManager`
- minSdk 26 (Android 8.0), targetSdk 34
