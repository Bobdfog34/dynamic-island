# Dynamic Island (Живой остров) для Android

Клон «Dynamic Island» с iPhone: плавающий остров вверху экрана, который показывает
уведомления, музыку, зарядку и таймер, поддерживает жесты и кастомизацию.

> **Версия 4.0** — дизайн **как на iPhone**: чистый чёрный остров, прижатый к верху,
> «раздвоение» на камеру, пружинные анимации, тап — открыть приложение, удержание —
> развернуть. Кольцо прогресса таймера и развёрнутый плеер музыки.

## Возможности

- 🔕 **Блокировка уведомлений** — уведомления приходят **только в остров** и скрываются из шторки; важные и системные можно оставить, есть список приложений-исключений
- 🔔 **Уведомления** — иконка и имя приложения; сообщения из одного приложения **группируются** в один блок со счётчиком и списком (разверни остров — увидишь все)
- 🎵 **Музыка** — обложка альбома, прогресс-бар и кнопки управления (назад / плей-пауза / вперёд) + живой эквалайзер
- ⚡ **Зарядка** — анимация заполнения батареи при подключении питания
- 🔋 **Низкий заряд** — предупреждение при 15% и ниже
- ⏱ **Таймер** — живой отсчёт + кольцо прогресса в стиле iPhone
- 👆 **Жесты как на iPhone** — тап по острову **открывает приложение**, **удержание** — развернуть/свернуть, перетаскивание пальцем
- 🖤 **Дизайн iPhone** — чисто чёрный остров у верхней кромки, «раздвоение» на камеру, обложка слева + эквалайзер справа
- 🎨 **Кастомизация** — ширина, высота, скругление, отступ сверху, прозрачность, цвет, рамка, свечение (кнопка **«Стиль iPhone»** возвращает к оригиналу)
- ✨ **Анимации** — пружинное раскрытие, мягкие переходы
- ⬆️ **Обновление из приложения** — проверка новых версий на GitHub и установка в один тап
- 🚀 **Автозапуск** при включении телефона

## Как пользоваться

1. Открой приложение.
2. Нажми **«Разрешить показ поверх других окон»** и включи переключатель.
3. Нажми **«Доступ к уведомлениям»** и включи доступ для Dynamic Island.
4. Включи переключатель **«Включить остров»**.
5. Настрой внешний вид ползунками (размер, скругление, прозрачность, цвет, свечение).

Остров можно перетаскивать пальцем. **Тап** — открыть приложение, **удержание** — развернуть/свернуть.

📺 Подробно — в [видео-инструкции](https://github.com/Bobdfog34/dynamic-island/releases/latest/download/instruction.mp4).

## Блокировка уведомлений (только остров)

1. Выдай **доступ к уведомлениям** (обязательно).
2. Включи переключатель **«Уведомления только в остров»**.
3. При необходимости нажми **«Приложения-исключения»** и отметь приложения,
   уведомления которых должны приходить как обычно (не блокироваться).

Как это работает: когда приходит уведомление, приложение отменяет его в системной
панели и показывает только в острове. Постоянные (музыка, навигация) и системные
уведомления не блокируются.

## Обновление

Приложение само проверяет новые релизы на GitHub и показывает список изменений.
Если доступна новая версия — появится кнопка **«Скачать новую версию»**, после чего
APK скачается и откроется установщик (может потребоваться разрешение на установку
из этого источника).

## Как собрать APK через GitHub (без ПК)

1. Форкни или загрузи проект в свой репозиторий (папка `.github/workflows/build.yml` обязательна).
2. Открой вкладку **Actions** — сборка запустится автоматически.
3. Дождись зелёной галочки ✅ (примерно 3–5 минут).
4. Скачай артефакт **DynamicIsland-debug** или создай релиз — APK приложится автоматически.

Если сборка не запустилась: **Actions → Build APK → Run workflow**.

## Локальная сборка

```bash
gradle assembleDebug
# APK: app/build/outputs/apk/debug/app-debug.apk
```

## Технологии

- Kotlin, AndroidX, Material Components
- `WindowManager` overlay + `ForegroundService`
- `NotificationListenerService` + `MediaSessionManager`
- `DownloadManager` + GitHub Releases API для автообновления
- minSdk 26 (Android 8.0), targetSdk 34
